# AI Development Resources

## Tool Used
ChatGPT

## Purpose
AI assistance was used to support the development and debugging of the GitHub pull request data pipeline.

## Development Prompt Summaries
The following are summaries of prompts and requests used during development, not exact transcripts.

1. Explain the basic structure of a Python project that extracts merged pull requests using GitHub REST API.
2. Explain how GitHub API authentication, pagination and pull request reviews work.
3. Help implement functions to extract and save reviews and check runs as JSON.
4. Help calculate whether a pull request was approved before merging.
5. Explain the difference between required, optional, skipped and successful status checks.
6. Help transform extracted JSON into a CSV report.
7. Help write unit tests using pytest and debug implementation errors.
